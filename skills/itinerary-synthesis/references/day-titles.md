# 每日標題：六個候選，使用者挑

每天寫 **6 個**標題候選放進 `days[].theme_candidates`，每個 `{text, shape, twist?, refs, riff_on?}`；
`theme` 先放你最推薦的那句（`theme_refs` 照抄它的 `refs`），然後**停下來請使用者挑**（`day_title_pick`）。
機器檢查在 `scripts/day_titles.py`（`itinerary-gate` 會跑）；好不好笑、有沒有詩意由使用者決定。

## 每個候選 = 一個句型 × 一個手法

| `shape` | 句型 | 例 |
|---|---|---|
| `couplet` | 兩拍對仗（兩段，用「，」接） | 早市的蟹，山頂的夜 |
| `sentence` | 一句話（一段） | 山頂的燈替整座港口守夜 |
| `triple` | 三連（三段） | 晨的蟹、午的倉、夜的燈 |
| `question` | 問句（以「？」結尾） | 夜景會等我嗎？ |
| `chiasmus` | 回環（兩段用同一組字倒過來） | 蟹看我，我看蟹 |
| `anadiplosis` | 頂真（前一段的尾字是下一段的頭） | 看海看到天，天上又有海 |
| `number` | 數字句 | 一天三碗丼 |
| `onomatopoeia` | 疊字擬聲（AA 或 ABAB） | 咕嚕咕嚕，泡進雪裡 |

不用：四字改寫、引用老梗、從…到…、比較句。

| `twist` | 手法 | 規則 |
|---|---|---|
| `rhyme` | 押韻 | 最後兩段的末字（略過句尾的了的啦呢嗎吧啊呀）**同韻轍、同聲調**，依台灣讀音（教育部《國語小字典》，`scripts/zhuyin.py`）；讀音判不出來的字不能標押韻 |
| `pun` | 諧音 | 必附 `riff_on`（原句），且真的改寫了它 |
| `contrast` | 反差 | — |
| `exaggerate` | 誇張 | — |
| `pov` | 換視角（讓風景當主角） | — |
| `swap` | 對調 | 必附 `riff_on` |
| `double_meaning` | 雙關 | 必附 `riff_on`（被雙關的那個說法） |
| `turn` | 轉折 | — |

回環、頂真、數字句、疊字擬聲本身就是文字遊戲，`twist` 可以不寫；其他句型一定要有手法。不用老梗。

韻轍（注音）：ㄚ／ㄛㄜ／ㄝ（ㄧㄝ ㄩㄝ）／ㄞ／ㄟ（ㄨㄟ）／ㄠ（ㄧㄠ）／ㄡ（ㄧㄡ）／ㄢ（ㄧㄢ ㄨㄢ ㄩㄢ）／
ㄣ（ㄧㄣ ㄨㄣ ㄩㄣ）／ㄤ（ㄧㄤ ㄨㄤ）／ㄥ（ㄧㄥ ㄨㄥ ㄩㄥ）／ㄧ（含ㄩ、ㄦ、ㄓㄔㄕㄖㄗㄘㄙ的空韻）／ㄨ。
例：蟹 ㄒㄧㄝˋ／夜 ㄧㄝˋ 押韻；杯 ㄅㄟ／堆 ㄉㄨㄟ 押韻；雪 ㄒㄩㄝˇ／街 ㄐㄧㄝ 同韻不同調，**不算**。

## 一天六句的配額（前 6 個）

- 至少 3 句**有畫面、收在畫面**：含一個畫面字（光燈夜霧煙湖海雪風香暖冷山河港月星雲晨湯影色浪潮霜火水…），
  最後一字不是「嗎了吃看呢吧啊喝買走去來做玩飽痛碎」，且不用口語詞（還要、繼續、得先、什麼、一下、東西、然後）。
- 至少 3 句**有梗**（用了上列手法之一）。同一句可兩邊都算。
- **骨架**（一整句／兩段／三段／問句）每種最多 2 句。
- **長短**：短（≤7 字）、中（8–10）、長（11–13）各 2 句；**13 字以內，標點也算**。
- **有所本**：`refs` 寫當天行程裡的 poi id；畫面必須是當天真的有（天黑後才到才寫燈、去了地獄谷才寫煙）。
  地名交給日期列與紀念章，標題裡不必再寫；不寫感受形容詞（美、療癒、難忘），不寫「XX之旅」。

## 整趟

- 同一個關鍵字（地名以外的名詞：蟹、行李、熊、啤酒…，詞表在 `scripts/day_titles.py::KEYWORDS`）最多出現在 2 天的候選裡。
- 回環、頂真、數字句、疊字擬聲各最多用在 2 天。
- 擬聲詞不重複，同一開頭字算重複（咕嚕／咕嘟）。

## 挑選（`day_title_pick`）

1. 跑 `python <plugin>/scripts/tripwork.py picker <slug>`：寫出 `work/<slug>/挑標題.html`（離線網頁，最上面還能換大標題），
   並印出同內容的純文字清單。把網頁路徑**和**純文字清單都給使用者。
2. 使用者在網頁挑完按「複製選擇」，或直接打字回覆，格式一行：
   `tripwork 標題 H=2 D1=3 D2="自己寫的" D5=+`（H 只在換大標題時出現；`+` = 再給我 3 個）。
3. 跑 `python <plugin>/scripts/tripwork.py picker <slug> '<那一行>'`，它把選擇寫回 `itinerary.yaml` 的 `theme`
   （自己寫的標 `theme_user_written: true`）與 `trip-brief.yaml` 的 `headline`。輸出有 `more:` 的那幾天
   （或 `H`），在該天的 `theme_candidates` 尾端**追加** 3 句（同樣守上面的規則，不和既有的重複；大標題則追加到
   `headline_candidates`），重跑步驟 1 再問一次。前面 6 句的編號不會變。
4. 使用者挑的結果不會被擋；相鄰兩天骨架相同、或同一手法用了超過三分之一的天數，gate 只會在 `notices` 提醒。
